# Lyric Sync

パステル調の作詞支援アプリ。HTML / CSS / JavaScriptだけで動き、バックエンド・DB・ビルドは不要です。

## 使い方

プロジェクト全体を既存の静的ファイルサーバーでHTTP配信し、`index.html` を開いてください。辞書も同じサーバーから読み込みます。ファイルを直接開く（file://）とブラウザーの制限で辞書を読み込めない場合があります。サーバーの起動は行っていません。

- タイトルと歌詞を編集すると、このブラウザーのlocalStorageへ自動保存されます。
- エクスポートの右隣のゴミ箱から、確認後に曲全体を初期化できます。タイトルと全パートを削除し、空のVerse 1（4行）に戻します。UI言語と表示設定は保持します。
- 歌詞の各行は「複製」「削除」で編集でき、「≡」をドラッグすると同じパート内で並び替えられます。上下キーでも移動でき、読みも一緒に移動します。
- 左の一覧でセクションに移動できます。「≡」をドラッグして並び替えられます（フォーカスして上下キーでも移動できます）。パート名は直接入力して変更でき、比較欄の隣のボタンで削除・複製できます。
- English / 日本語はUIの表示言語のみを切り替えます。ボタン、モーダル、通知、読み上げ用ラベルも切り替わり、タイトル・パート名・歌詞はそのまま保持します。カウント方式は各行の歌詞から自動判定します。
- かな・漢字を含む行は日本語のモーラ数、英字の行は英語の音節数を表示します。よみがな欄はUI言語に関係なく日本語の行に表示し、入力中に自動で切り替わります。日本語と英語が同じ行に混ざる場合は日本語として扱い、読めない語はかなのよみがなで補えます。異なるカウント方式の行同士は数値の比較を行いません。
- 英語はCMUdictの発音に含まれる母音の数を合計します。辞書にない語は綴りから推定し、`≈` を表示します。発音によって音節数が違う語は辞書の最初の発音を使用し、カウントにマウスを重ねると説明を表示します。
- 日本語はkuromoji.js / IPADICで発音を取得してモーラ数を数えます。拗音・外来語の小書き母音は前のかなとまとめ、促音・撥音・長音は各1モーラとして数えます。自動読みは読み入力欄のヒントとして表示し、手入力した読みを優先します。自動読みは保存データに書き込みません。読めない漢字や英数字は文字数で代用せず `?` を表示します。かなの読みを入力してください。
- 比較欄で他のパートを選ぶと、そのパートの現在の数値と比較できます。赤いドットは比較先より多い音、灰色のドットは足りない音を示します。
- 上部の下向き矢印からJSONまたはテキストを書き出せます。上向き矢印から読み込みます。JSONには読み・基準・表示設定も含まれます。
- テキストは `[Verse 1]` などのパート名の次行から歌詞を書く形式で読み込めます。エクスポートしたテキストのパート順・空行を保持し、読みは空欄になります。曲名にはファイル名を使用します。パート名のないテキストは1つのパートとして読み込みます。

ブラウザーのデータを消すと自動保存も消えるため、残したい曲はJSONを書き出してください。フォントはGoogle Fontsから読み込みますが、接続できない場合はシステムフォントで動作します。

## 辞書と確認

辞書はローカル配信し、歌詞を外部サービスへ送信しません。辞書は歌詞から判定した言語について初回だけ読み込みます。読み込みが完了するとカウントと比較表示を自動更新します。辞書の利用条件・取得元は `dictionaries/README.md` に記載しています。

左側の「ライセンス」リンクから `licenses.html` を別タブで開けます。CMUdict、kuromoji.js、IPADICのライセンス・著作権表示・免責事項を掲載しています。公開時もライセンス文書とこのページを一緒に配信してください。原文ファイルを更新した場合は `node build-licenses.cjs` でページを再生成できます。

`node check-counter.cjs` で同梱のブラウザー用kuromojiと実際の辞書を使ったカウントを確認できます。`node check-language.cjs` で言語切り替えを確認できます。どちらもサーバーを起動しません。

`node check-mobile.cjs` は `crypto.randomUUID`・`structuredClone`・`ResizeObserver` が使えない環境での起動と主要操作を確認します。ローカルネットワーク内のHTTP接続でも初期化できます。

## PWA

HTTPSで配信するとホーム画面への追加・独立ウィンドウでの起動・オフライン編集に対応します。localhostは開発用の例外ですが、スマホからLAN内のIPアドレスへ通常のHTTPで接続した場合はService Workerを利用できません。サーバーやHTTPS設定は起動・変更していません。

- iPhone / iPad：Safariの共有メニューから「ホーム画面に追加」。
- Android：対応ブラウザーのメニューからインストールまたは「ホーム画面に追加」。
- 初回オンラインアクセスでアプリと英語・日本語辞書のキャッシュを作成します（約25MB）。完了後はオフラインでも編集・カウント・エクスポート・ライセンス閲覧ができます。保存領域をブラウザーやOSが削除した場合は再度オンラインで開いてください。
- アプリを閉じる・バックグラウンドに移る際にも歌詞を保存します。ブラウザーとホーム画面アプリで保存領域が異なる場合があるので、曲の移行にはJSONを使ってください。
- 更新は開いているアプリを強制リロードせず、すべてのアプリタブ／ウィンドウを閉じた後の次回起動で適用します。

ファイル変更後は `node build-licenses.cjs`（ライセンスページも更新する場合）、`node build-pwa.cjs` を実行して `sw.js` のキャッシュバージョンを再生成し、プロジェクトと一緒に配信してください。`sw.js` は長期キャッシュせず再検証できる配信設定にしてください。`node check-pwa.cjs` でオフラインキャッシュとマニフェストをサーバーなしで検証できます。
